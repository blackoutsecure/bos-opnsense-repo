# Documentation

Start with [the repository baseline](repository-baseline.md).

Every new feature must add:

- Overview and intended users
- Architecture and trust boundaries
- Installation on explicitly supported native platform versions
- Upgrade and configuration-migration procedures
- Rollback and recovery procedures
- Security review and validation evidence

Document untested behavior as **Not Assessed**, not as a pass. Cloudflare Pages
is the intended documentation publication target; no site is deployed yet.
