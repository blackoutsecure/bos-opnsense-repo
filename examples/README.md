# Examples

Only sanitized, non-secret examples belong here.

- Use clearly marked placeholders, never real tokens, private keys, customer
  identifiers, configuration backups, or signing material.
- Preserve TLS certificate validation in every example.
- Use FreeBSD-native commands and OPNsense conventions.
- Explain required permissions and how sensitive configuration is stored.
- Do not present Linux-only commands as OPNsense installation procedures.

There are no runnable integration examples yet.
