# OPNsense Plugins

These are documentation scaffolds, not installable OPNsense plugins.

| Plugin | Planned scope | State |
| --- | --- | --- |
| [os-blackoutsecure-azure](os-blackoutsecure-azure/README.md) | Azure integration | Planned |
| [os-blackoutsecure-cloudflare](os-blackoutsecure-cloudflare/README.md) | Cloudflare integration | Planned |
| [os-blackoutsecure-observability](os-blackoutsecure-observability/README.md) | Observability integration | Planned |

Each directory contains `README.md`, `CHANGELOG.md`, `SECURITY.md`, and `LICENSE`.
No placeholder manifest or service is included.

Follow [official OPNsense plugin conventions](https://github.com/opnsense/plugins)
and [the contribution requirements](../CONTRIBUTING.md) when implementing them.
Native versions, ABIs, API features, and permissions must be selected and
validated before a compatibility or release claim is made.
